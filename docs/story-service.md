# R1-A 서비스 맥락

- 기준 문서: `docs/prd.md`
- 범위: MVP 1차
- 상태: 사용자 승인 완료
- 구매·정산·허들링 픽·미션 피드백은 MVP 1차 범위에서 제외한다.

## 유저스토리

| 번호 | 유저스토리 | PRD 근거 |
| --- | --- | --- |
| 1 | 무료 학습자가 공개 학습자료와 유료 콘텐츠 미리보기를 탐색한다. | §3-1, §6-1 |
| 2 | 유료 멤버가 강의자료와 스킬·프롬프트를 열람하고 사용한다. | §6-2, §6-3 |
| 3 | 유료 멤버가 미션 산출물을 제출하고 제출 완료된 산출물을 내 자산으로 전환한다. | §6-4 |
| 4 | 판매 승인 회원이 자신의 자산을 판매 신청하고 검수 상태를 확인한다. | §6-5, §7-4 |
| 5 | 운영자가 판매 회원을 수동 승인하고 판매 신청 자산을 체크리스트로 검수하여 승인·수정 요청·반려한다. | §6-7 |

## 이 서비스에서 어기면 안 되는 것

| ID | 불변 조건 | PRD 근거 |
| --- | --- | --- |
| INV-01 | 멤버가 만든 자료는 기본적으로 비공개이며, 본인이 선택한 경우에만 멤버 공개 또는 판매 신청이 가능하다. | §14 |
| INV-02 | 판매 신청은 판매 승인 회원만 할 수 있으며, 판매 자산은 운영자 검수를 통과해야 한다. | §7-4, §9, §14 |

## 기계 판정 조건의 방향

- INV-01: 기본 비공개 위반 0건, 소유자 선택 없는 공개 전환 0건.
- INV-02: 미승인 회원의 판매 신청 성공 0건, 운영자 검수 없는 승인 0건.
- 구체적인 검사 입력, 검사 방법과 판정 스크립트는 R5에서 확정한다.
- 위 불변 조건은 서비스 판정 기준이다. R1-B의 실제 수작업 흐름을 추정하거나 구성하는 재료로 사용하지 않는다.
